# Product Overview

## Problem

Traffic congestion in Colombo, Kandy and Gampaha delays work, school, deliveries and emergency response. Fixed-time lights do not react to live demand.

## Innovation

**Smart Traffic Management System (STMS)** — a conceptual platform that combines cameras, sensors, GPS, AI/ML suggestions and a control dashboard for one busy signal-controlled Colombo junction.

This prototype uses **dummy/sample data only**. It is not connected to real traffic controllers.

## Users

| Role | Need |
|------|------|
| Traffic authority / Police operator | Live junction view, incidents, approve/reject signal suggestions |
| Transport planner | Analytics, peak-hour patterns, pilot comparison |
| Driver / public | Simple route alerts (“Heavy traffic ahead…”) |
| Maintenance tech | Device health (camera/sensor/controller) |

## Pilot scope

- One fictional junction: **Bambalapitiya / Galle Road Junction (Pilot)**
- Illustrative timings: **30s normal green → 50s heavy green**
- Human supervision required for every AI recommendation
- Pedestrian crossing times remain protected in the story
