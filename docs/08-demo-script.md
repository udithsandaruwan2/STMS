# Demo Script (3–5 minutes)

1. **Open Monitor** — Introduce STMS as a Colombo junction pilot with sample data.
2. **Show live queues** — Point at North approach building a queue during “morning peak”.
3. **Notifications** — Highlight congestion / device / ambulance sample events.
4. **Control** — Open AI suggestion to extend green 30→50s; explain human review; Approve.
5. **Faults** — Show a degraded sensor and the fallback fixed-plan banner.
6. **Analytics** — Hourly volume chart and before/after wait comparison.
7. **Digital Twin** — Toggle adaptive mode and show illustrative wait change.
8. **Driver** — Show public alert: “Heavy traffic ahead; consider another route.”
9. **Close** — Emphasize: conceptual prototype, supervised pilot would be next step.
